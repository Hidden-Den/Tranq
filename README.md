Tranq превращает живую русскую речь в текст, который не стыдно отправить. Слова-паразиты, оговорки, самоисправления и повторы мыслей убираются, а ваши слова, числа и факты остаются на месте. Латинские термины вроде Kubernetes, PostgreSQL или Figma пишутся латиницей.

Речь распознаётся прямо на Mac моделью **GigaAM v3** от Сбера, звук никуда не уходит. Очистку делает языковая модель на ваш выбор: локальная без сети, внешний API или корпоративный шлюз.

**Было:** «Ну, короче, я завтра, эээ, в среду, с утра поеду в офис и, типа, заберу ноутбук.»
**Стало:** «Я в среду с утра поеду в офис и заберу ноутбук.»

## Возможности

- **Распознавание без сети.** GigaAM v3 работает на устройстве. Для английской речи есть Whisper.
- **Очистка речи.** Убирает «ну», «короче», «э-э», оговорки и повторы, не пересказывает и не сокращает мысль.
- **Проверка ответа модели.** Если модель потеряла число или придумала слово, вставится текст без её правок.
- **Длинные диктовки.** Речь длиннее 1200 знаков чистится кусками и вставляется абзацами.
- **Три способа обработки:** локальная модель без сети, внешний API или корпоративный шлюз.
- **Тоны для приложений и сайтов.** Деловой для рабочей почты, живой для мессенджера, свой — какой захотите.
- **Словарь терминов** со встроенными наборами и вашими словами. Учится на ваших правках.
- **Вставка под курсор** в любое приложение.
- **История** с итоговым текстом, сырой расшифровкой и записью голоса. Закрывается Touch ID.
- **Доступ для нейронок.** Claude Code, Cursor, Codex и другие агенты могут пополнять ваш словарь.

## Быстрый старт

1. Скачайте `Tranq.dmg` со [страницы релизов](https://github.com/Hidden-Den/Tranq/releases/latest) и перетащите `Tranq.app` в «Программы».
2. Сборка подписана без платного сертификата Apple, поэтому при первом запуске выполните в Терминале:

   ```bash
   xattr -cr /Applications/Tranq.app
   ```

   Или откройте приложение через правый клик → «Открыть» → «Открыть».
3. Выдайте разрешения:
   - **Микрофон** — чтобы записывать речь.
   - **Универсальный доступ** — чтобы вставлять текст в активное окно и слышать клавишу `Fn`.
4. Нажмите `⌥ Пробел`, скажите фразу и нажмите ещё раз. Текст появится в активном поле.
5. Для полной очистки выберите модель в **Настройки → Обработка**. Без неё Tranq убирает только звуки и заикания. Какую выбрать — в разделе [Способ обработки](#способ-обработки).

**Требования:** Mac на Apple Silicon с macOS 13.5 или новее, около 300 МБ на диске. Локальная модель очистки занимает ещё 3–5 ГБ и скачивается по желанию.

## Диктовка

| Действие | Как |
| :--- | :--- |
| Начать и закончить диктовку | `⌥ Пробел`, клавишу можно сменить |
| Отменить диктовку | `Esc` |
| Вставить сырую расшифровку последней диктовки | `⌥ ⌘ Z` |
| Открыть настройки | `⌘ ,` или значок в строке меню |

**Горячая клавиша** меняется в **Настройки → Диктовка**: подойдёт любое сочетание или одиночный модификатор, например `Fn`. Кнопка «Сбросить» вернёт `⌥ Пробел`.

**Два режима клавиши:**

- **Переключение.** Первое нажатие начинает запись, второе останавливает и вставляет текст. Удобно для длинных мыслей.
- **Рация.** Держите клавишу, пока говорите, отпустите — текст вставится. Удобно для коротких фраз.

Режим и звуки быстро переключаются из значка **q** в строке меню.

**Отмена.** `Esc` останавливает запись без вставки. Если вы говорили дольше трёх секунд, запись всё равно сохранится в историю, чтобы сказанное не пропало.

**Модель перестаралась?** `⌥ ⌘ Z` вставит в то же окно сырую расшифровку последней диктовки, как вы её сказали.

**Авто-вставка.** Если её выключить, текст не вставляется, а кладётся в буфер обмена — вставите сами через `⌘ V`. Без Универсального доступа Tranq тоже кладёт текст в буфер.

**Подсветка окна.** Во время записи окно, куда пойдёт текст, обводится салатовой рамкой. Выключается в **Настройки → Диктовка**.

**Звуки** отмечают начало и конец записи, копирование и ошибки. Тоже выключаются в **Настройки → Диктовка**.

## Как Tranq чистит текст

Каждая диктовка проходит несколько шагов:

1. **Распознавание.** GigaAM превращает звук в текст на вашем Mac.
2. **Чистка без модели.** Убираются звуки вроде «э-э» и заикания, расставляются заглавные буквы и абзацы. Этот шаг работает всегда, даже без сети и без модели.
3. **Словарь.** Термины из ваших наборов исправляются: «кубернетис» становится Kubernetes.
4. **Очистка моделью**, если она выбрана. Модель убирает слова-паразиты, самоисправления и повторы мыслей. Она не пересказывает, не отвечает на вопросы из диктовки и не выполняет просьбы — текст диктуется для другого места.
5. **Проверка.** Если в ответе модели пропало число, латинский термин или появилось слово, которого вы не говорили, вставляется текст второго шага.

Речь длиннее 1200 знаков делится на куски до 800 знаков по концам предложений. Каждый кусок чистится отдельно и вставляется абзацем. Кусок, который не прошёл проверку, вставляется как сказан, остальные — чистыми.

## Способ обработки: локально, API или шлюз

Выбирается в **Настройки → Обработка**: движок **Air-Gapped** — локальная модель на Mac, **Внешний** — модель по API из раздела **Провайдер**.

| | Локальная модель | Внешний API | Корпоративный шлюз |
| :--- | :--- | :--- | :--- |
| Сеть | не нужна | нужна | нужна сеть компании или VPN |
| Куда уходит текст | никуда | провайдеру | на сервер компании |
| Качество | хорошее | лучшее | зависит от модели шлюза |
| Стоимость | бесплатно | по тарифу провайдера | за счёт компании |
| Место на диске | 3–5 ГБ | — | — |

### Локальные модели

Работают на Mac без интернета через встроенный llama-server. Модель скачивается с Hugging Face кнопкой в **Настройки → Обработка**, рекомендованная для вашего Mac отмечена словом «Рекомендуем».

| Модель | Размер | Памяти Mac | Для кого |
| :--- | :--- | :--- | :--- |
| **Gemma 4 E2B** | 3,1 ГБ | от 8 ГБ | Mac с 8 ГБ памяти, например базовые MacBook Air на M1 и M2. Самая быстрая |
| **Gemma 4 E4B** | 4,2 ГБ | от 16 ГБ | рекомендуется для Mac с 16 ГБ и больше. Лучший баланс качества и скорости |
| **T-lite 2.1** | 5,0 ГБ | от 16 ГБ | хорошо знает русский, чуть точнее с терминами |

На Mac с 8 ГБ модели для 16 ГБ подписаны «Нужно 16 ГБ»: они запустятся, но будут мешать другим программам.

Замер на 100 фразах на Apple M5 Pro: Gemma 4 E2B отвечает в среднем за 0,15 с, Gemma 4 E4B за 0,26 с, T-lite 2.1 за 0,30 с. Подробности: [замер локальных моделей](docs/eval-local-models-2026-11.md).

### Внешний API

В **Настройки → Провайдер** выберите пресет, вставьте ключ и нажмите проверку соединения.

| Провайдер | Модель по умолчанию | Где взять ключ |
| :--- | :--- | :--- |
| OpenRouter | `anthropic/claude-haiku-5.5` | [openrouter.ai/keys](https://openrouter.ai/keys) — один ключ на сотни моделей |
| OpenAI | `gpt-6-luna` | [platform.openai.com/api-keys](https://platform.openai.com/api-keys) |
| Anthropic | `claude-haiku-5-5` | [console.anthropic.com](https://console.anthropic.com/settings/keys) |
| DeepSeek | `deepseek-chat` | [platform.deepseek.com](https://platform.deepseek.com/api_keys) |
| Ollama локально | `llama3.2` | ключ не нужен; подойдёт и LM Studio или другой локальный сервер |

Для очистки хватает быстрых недорогих моделей: класса Haiku, Flash или mini. Большие модели думают дольше, а диктовка ждёт ответа.

Поле **Модель** можно поменять на любую модель провайдера. Счётчики токенов и задержек включаются в том же разделе и хранятся только на Mac.

### Корпоративный шлюз

Любой сервер с API в формате OpenAI, например внутренний шлюз компании. Укажите адрес вида `https://gateway.company.ru/v1`, ключ и модель.

Если шлюз недоступен, например выключен VPN, вставляется текст без модели, а на экране записи появляется пометка «Шлюз недоступен». Запасного перехода на внешний сервис нет: текст не уйдёт туда, куда вы его не отправляли.

## Инструкция модели

В **Настройки → Обработка → Инструкция модели** лежит системный промпт, по которому модель чистит текст. По умолчанию он говорит модели:

- удалить слова-паразиты и заминки;
- оставить последний вариант, если говорящий поправил себя;
- из нескольких формулировок одной мысли оставить самую полную;
- сохранить слова говорящего, факты, числа, имена и термины, ничего не добавлять;
- вопрос оставить вопросом, просьбу просьбой — не отвечать и не выполнять;
- не пересказывать и не сокращать мысль до вывода.

Инструкцию можно дописать, например «пиши числа цифрами» или «обращайся на вы». Кнопка **По умолчанию** вернёт исходный текст.

Правьте осторожно: проверка ответа всё равно работает, и если инструкция заставит модель сильно переписывать речь, Tranq будет чаще вставлять текст без её правок.

## Правила и тоны для приложений и сайтов

Раздел **Правила** в боковом меню. Правило задаёт тон для конкретного приложения или сайта в активной вкладке браузера. Без правила везде одинаковая чистая речь.

**Как добавить правило:**

1. Откройте **Правила** и нажмите добавить.
2. Выберите **Приложение** из списка или **Сайт** и впишите адрес, например `mail.google.com`. Правило для сайта действует и на его поддомены.
3. Выберите тон.

Правило можно временно выключить, не удаляя.

**Тоны:**

| Тон | Что делает | Мат и грубость |
| :--- | :--- | :--- |
| **Деловой** | вежливо и по делу, полными предложениями, без разговорных слов. Резкость передаёт твёрдыми деловыми словами, а не убирает | убирает, передаёт смысл деловыми словами |
| **Живой** | коротко и просто, как в переписке с коллегой | оставляет как сказано |
| **Свой** | ваше описание тона своими словами | оставляет как сказано |

**Примеры своего тона:**

- Личный: «тепло и по-дружески, на ты, коротко».
- Рабочий чат: «сжато, списком, если перечисляю задачи».
- Для клиентов: «на вы, спокойно и уверенно, без канцелярита».

Тон меняет только стиль. Он не отвечает вместо вас, не добавляет вежливых формул и пожеланий, которых вы не говорили. Поручение другому человеку остаётся поручением: «скажи Ольге, чтобы прислала счёт» не превратится в письмо Ольге.

Тон работает только с моделью очистки. Без модели правила не применяются.

## Словарь

Раздел **Словарь** в боковом меню помогает писать термины, имена и названия правильно.

### Встроенные наборы

IT, AI, бизнес, менеджмент, маркетинг, дизайн, финансы, HR, юриспруденция, медицина, психология и названия приложений. Включайте только нужные: меньше наборов — меньше ложных замен.

Латинские термины пишутся латиницей, русские аббревиатуры вроде БТИ остаются кириллицей.

### Мои слова

Добавьте слово, которое распознавание пишет неправильно: фамилию, название продукта, внутренний термин.

1. Нажмите добавить в разделе **Словарь**.
2. В поле **Слово** напишите, как слово должно выглядеть: `Kubernetes`.
3. В **Узнаю как** добавьте варианты, как его слышит распознавание: `кубернетис`, `кубер нетис`.
4. Не знаете, как оно слышится? Нажмите **Произнести** и скажите слово. Tranq покажет «Услышал: …» — нажмите **Сохранить**, и вариант добавится сам.

У слова можно добавить варианты кнопкой **+ вариант** или удалить лишние.

### Обучение на правках

Если включено **Учиться на правках**, словарь запоминает, как вы исправляете текст заметок в истории. Выученные слова помечены «выучено» и удаляются как обычные.

### Слова от нейронок

Слова и наборы, которые добавил ИИ-агент, помечены «от агента». Одно действие удаляет их все, ваши слова останутся.

| Модель | Язык | Размер | Как получить |
| :--- | :--- | :--- | :--- |
| **GigaAM v3** | русский | 273 МБ | уже внутри приложения |

## История

Каждая диктовка сохраняется заметкой.

- **Итог и Сказано.** Переключатель показывает итоговый текст или сырую расшифровку — удобно проверить, что поменяла модель.
- **Правка по клику.** Исправьте текст прямо в заметке, словарь запомнит исправление.
- **Запись голоса.** Можно переслушать, что вы на самом деле сказали.
- **Новые заметки.** Если главное окно скрыто, законченная диктовка открывает историю. Если окно открыто, новая заметка ждёт с точкой непрочитанного. Отключается в **Настройки → Приложение → Сразу открывать в истории**.

### Замок истории

**Настройки → Данные → Замок истории.**

- История открывается по Touch ID или паролю Mac.
- Заметки, звук и журнал диктовок шифруются на диске.
- История запирается при сне Mac и через 15 минут со скрытым окном.
- Диктовать при запертой истории можно, новые заметки появятся после разблокировки.
- Ключ шифрования привязан к этому Mac: на Mac с Secure Enclave он не покидает чип, на остальных лежит в связке ключей входа. На другом Mac история не прочитается, поэтому перед переездом сохраните открытую копию кнопкой **Выгрузить**.

**Стереть историю** в том же разделе удаляет заметки, звук, журнал, логи и ключ безвозвратно.

## Приватность и ключи

- **Звук** распознаётся на Mac и никуда не отправляется.
- **Текст** уходит только в выбранную модель очистки. С локальной моделью он не покидает Mac.
- **Аналитики и телеметрии нет.** Счётчики токенов и задержек API хранятся только локально и по умолчанию скрыты.
- **Сеть** приложение использует само только для проверки обновлений на GitHub, а модели скачивает по вашей кнопке.
- **Ключ шифрования истории** хранится в Secure Enclave или в связке ключей macOS.
- **Ключи API** хранятся в настройках приложения на диске, а не в связке ключей. Их могут прочитать программы, запущенные под вашей учётной записью. Используйте отдельный ключ для Tranq с лимитом расходов.

Подробно: [Приватность и данные](docs/privacy.md).

## Доступ для нейронок

Tranq может отдать словарь ИИ-агенту — Claude Code, Cursor, Codex, Gemini CLI, Antigravity — по протоколу MCP. Агент добавит ваши термины с вариантами произношения или соберёт тематический набор. С отдельным разрешением он прочитает историю и найдёт слова, которые распознавание пишет неправильно.

Всё выключено по умолчанию и включается в **Настройки → Данные**. Там же готовый конфиг для копирования. Подробно: [Доступ для нейронок](docs/mcp.md).

## Обновления

Tranq раз в несколько часов проверяет страницу релизов и сообщает о новой версии. Чтобы обновиться, скачайте новый `Tranq.dmg`, замените приложение в «Программах» и снова выполните `xattr -cr /Applications/Tranq.app`. Права Универсального доступа подтянутся через минуту-две.

Что поменялось в каждой версии — в [CHANGELOG](CHANGELOG.md).
