# Телеметрия внешнего API

Дата: 2026-11-18. Короткий проект.

## Зачем

При тестировании внешнего API не видно ни расхода токенов, ни того, где теряется
время. Нужны цифры, чтобы следить за расходом, сравнивать модели и находить
причину задержек.

Это инструмент отладки, а не витрина: обычному пользователю диктовки он не нужен
и по умолчанию не показывается.

## Цели

- Входящие и исходящие токены: за сеанс, накопительно и в среднем.
- Задержка: время до первого токена и полное время ответа.
- Исход запроса: успех, таймаут, ошибка. Автоматического отката на локальную модель в приложении нет, поэтому исхода «откат» тоже нет.
- Сравнение моделей между собой, локальная модель в том же списке.

## Не цели

- Графики и история по дням.
- Пересчёт в деньги: тарифы меняются, держать их в приложении нельзя.
- Отправка телеметрии куда-либо наружу. Данные остаются на машине.

## Ограничения

- Чистка идёт потоком, `CleanupBackends.swift`. В потоке провайдеры по умолчанию
  токены не присылают.
- У части провайдеров блока `usage` может не быть вовсе.
- Локальная модель токенов не сообщает, но её задержки сравнивать полезно.

## Способы

1. **Замеры внутри каждого бэкенда.** Отвергнут: локальная модель и внешний API
   считались бы по-разному, код размазался бы по трём файлам.
2. **Обёртка вокруг единственной точки вызова**, `ThoughtSynthesizer.swift:93`.
   Выбран: задержки и исход считаются одинаково для любого бэкенда. Токены
   приходят отдельным каналом из разбора потока.

Точность токенов: берём цифры провайдера, а где их нет — оценку по символам с
пометкой. Отвергнута чистая оценка: расходится со счётом провайдера. Отвергнуты
только точные цифры: у части провайдеров числа не было бы вовсе.

## Решения

Сбор на каждую чистку: модель, входящие и исходящие токены с пометкой точности,
время до первого токена, полное время, исход.

Запрос: `stream_options.include_usage` для формата OpenAI, `usage.include` для
OpenRouter, разбор `message_start` и `message_delta` для Anthropic.

Хранение: `CleanupTelemetry`, файл `telemetry.json` в Application Support. Накопительные итоги по каждой
модели живут всегда, последние 50 записей держатся для средних и для списка
последних запросов.

Среднее время ответа считается по успешным запросам: таймауты видны в счётчике отказов и не тянут среднее к лимиту ожидания. Локальная модель токенов не сообщает: у неё в списке прочерк, а время до первого токена пусто.

Показ: строка «Телеметрия» в разделе API, свёрнута по умолчанию, раскрывается
нажатием. Состояние между запусками не запоминается. Паттерн раскрывашки тот же,
что у словарных пакетов в `DictionaryView.swift`. Внутри: цифры активной модели,
общий расход по всем моделям, последние пять запросов строками и сброс.

## Оставлено исполнителю

Формат чисел, точные отступы, размер окна записей.
