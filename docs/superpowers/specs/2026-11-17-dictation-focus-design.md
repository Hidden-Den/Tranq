# Голосок 2.3: фокус на диктовке, уровни очистки и правила приложений

Дата: 17 ноября 2026
Статус: согласовано в обсуждении, готово к плану работ
Версия релиза: `2.3.0`, новая функциональность

---

## 1. Цель

Голосок — лёгкая диктовка для macOS. Нажал клавишу, сказал, в активное поле вставился чистый, лаконичный текст.

- Речь: 100% русский, с латинскими терминами. Английские диктовки не поддерживаем.
- Основная ценность: убрать паразиты, самоисправления и повторы мыслей, сохранив слова и факты говорящего.
- Тон под приложение и режим промпта — только по выбору пользователя.
- Три способа обработки: локально без сети, внешний API, корпоративный шлюз за VPN.

## 3. Уровни очистки

Пример диктовки:

> «Слушай, ну короче, я тут подумал, что нам надо перенести встречу, ну то есть встречу с клиентом, на четверг, потому что в среду я не успеваю, ну не успею подготовить презентацию, короче давай на четверг перенесём»

| Уровень | Что делает | Пример результата | Нужна модель |
| --- | --- | --- | --- |
| A, дословно | Звуковые паразиты, заикания, числа цифрами | «Я тут подумал, что нам надо перенести встречу, встречу с клиентом, на четверг…» | Нет |
| B, чисто | A плюс слова-паразиты, самоисправления, повторы мыслей; слова говорящего | «Давай перенесём встречу с клиентом на четверг: в среду я не успею подготовить презентацию» | Да |
| C, переписать | B плюс тон и структура по правилу пользователя | «Добрый день! Предлагаю перенести встречу с клиентом на четверг…» | Да |

### 3.1. Когда вызывается модель

- Уровень A никогда не вызывает модель.
- Уровень B вызывает модель для всех фраз длиннее 3 слов. Текущий пропуск модели по `DisfluencyPrefilter.needsCleanup` убрать для B: повтор мысли без паразитов правилами не обнаружить.
- Если модель недоступна, не уложилась по времени или её ответ отклонён, вставляется A.

### 3.2. Валидатор по уровням

`GroundingValidator` получает уровень вместо текущего `VoiceStyle`.

| Проверка | B | C | Промпт |
| --- | --- | --- | --- |
| Мета-зачины «Конечно, вот…» | Да | Да | Да |
| Вопрос остаётся вопросом | Да | Да | Нет |
| Все числа сохранены, новых нет | Да | Да | Новых нет |
| Новые латинские слова только из речи или словаря | Да | Да | Нет |
| Доля новых слов | До 20% | Нет | Нет |
| Доля сохранённых слов | Нет | Нет | Нет |
| Предел длины | 1.2 от речи | 2.0 от речи | 3.0 от речи |

Главное изменение: порог `minRetainedWordShare` для B снимается. Сокращение повторов — цель уровня B, а не ошибка.

### 3.3. Промпт B

Заменяет `VoiceIntelligenceSettings.defaultCustomPrompt`. Суть:

1. Удали слова-паразиты и заминки.
2. При самоисправлении оставь только финальный вариант.
3. Если мысль повторена несколькими формулировками, оставь одну, самую полную.
4. Используй слова говорящего, не подбирай синонимы и не меняй тон.
5. Факты, числа, имена и термины сохрани; ничего не добавляй.
6. Вопрос оставь вопросом, просьбу — просьбой; не отвечай и не выполняй.
7. Выведи только текст.

Окончательная формулировка подбирается по набору замеров, раздел 11.

## 4. Правила приложений и сайтов

### 4.1. Модель

```swift
struct DictationRule: Codable, Identifiable {
    let id: UUID
    var target: Target          // .app(bundleId) или .site(domain)
    var displayName: String     // «Outlook», «mail.company.ru»
    var tone: Tone              // .business, .casual или .custom(prompt)
    var isEnabled: Bool
}
```

- Правил по умолчанию нет. Пользователь добавляет их сам.
- При добавлении предлагаются готовые тона: «Деловой», «Живой». Можно написать свой промпт.
- Правило включает уровень C с заданным тоном.
- `AppProfileRouter` и `AppCategory` с зашитыми категориями удаляются.

### 4.2. Определение цели

В момент нажатия клавиши, вместе с `FocusSnapshot`:

1. Если активное приложение — браузер, прочитать адрес активной вкладки через Accessibility: атрибут `AXURL` у `AXWebArea` в фокусном окне. Разрешение «Универсальный доступ» уже есть. Поддержка: Safari, Chrome и браузеры на Chromium; Firefox — по возможности.
2. Найти правило по домену с учётом поддоменов: правило `company.ru` срабатывает для `mail.company.ru`.
3. Если правила по сайту нет, искать правило по bundle id приложения.
4. Если ничего не нашлось или адрес не прочитался, использовать B.

Адрес вкладки не сохраняется и не уходит в модель; в журнал пишется только сработавшее правило.

### 4.3. Интерфейс

Раздел настроек «Приложения»: список правил, кнопка «Добавить». В листе добавления — выбор приложения из запущенных или ввод домена, выбор тона. Подписи без скобок, до 8 слов.

## 5. Режим промпта

- Переключатель в настройках «Режим промпта», по умолчанию выключен.
- Когда включён: основное сочетание с Shift запускает диктовку в режиме промпта только для этой записи. Для клавиши Fn — Fn с Shift.
- Обычное сочетание всегда даёт B или правило приложения, в том числе в ChatGPT и Claude.
- На экране записи подпись только для необычного режима: «Промпт» или имя правила. Обычная очистка не подписывается.
- Промпт режима: превратить мысль в запрос к нейросети с контекстом, задачей и ограничениями, не меняя того, кто к кому обращается. Пример: «Помоги составить сообщение клиенту о переносе встречи со среды на четверг. Причина: не успеваю подготовить презентацию».

## 6. Офлайн-режим

- Модель выбирает пользователь; автоматического переключения нет.
- В списке моделей метка «Рекомендуем» по объёму памяти:
  - меньше 16 ГБ — QVikhr 2.5 1.5B, с пометкой «Повторы чистит хуже»;
  - от 16 ГБ — QVikhr 3 4B.
- Слабая модель всё равно работает на уровне B; если ответ отклонён, вставляется A.
- Каталог сократить до моделей, которые реально проходят набор замеров.

## 7. Внешние провайдеры и корпоративный шлюз

### 7.1. Корпоративный шлюз

- Новый пресет «Корпоративный шлюз»: пустой адрес, ключ, имя модели вводится вручную.
- Формат OpenAI `/chat/completions`.
- Заголовки `HTTP-Referer` и `X-Title` отправляются только на OpenRouter, на остальные адреса — нет.
- Шлюз недоступен из-за выключенного VPN или любой сетевой ошибки: вставляется A, на экране записи пометка «Шлюз недоступен». Запасного перехода на локальную модель или внешний сервис нет.
- Сертификаты: используется системная связка ключей, отдельной настройки нет.

### 7.2. Общее для провайдеров

- Ожидание ответа по умолчанию 6 секунд вместо 3.
- При откате на A из-за ошибки или ожидания — короткая пометка на экране записи, а не молчаливая подмена.
- Обновить модели по умолчанию в пресетах OpenAI и Anthropic на актуальные быстрые; конкретные ID уточнить при реализации.
- Удалить неиспользуемую настройку `voice.openRouterModel`.
- Определение формата Anthropic только по выбранному пресету, не по адресу.

### 8.2. Правки словарей и очистки

- Пакет IT: добавить `staging` («стейджинг»), `pull request` («пулл реквест», «пул-реквест»), проверить `Git` против «гид».
- Пакет HR: добавить `C&B` («си энд би», «си эн би», «компенсейшн энд бенефитс»).
- Проверить пакеты на латинские написания для слов с русскими окончаниями, например «деплой».
- `DisfluencyPrefilter`: схлопывать повтор слова и через точку — «Deploy. Deploy.» → «Deploy.».

## 9. История

Экран заметки:

- Одна строка: дата и время, длительность серым, переключатель «Итог / Сказано», «Скопировать», меню «⋯».
- В «⋯»: «Вставить ещё раз», «Удалить».
- Текст правится по клику, правки по-прежнему учат словарь.
- Плеер — тонкая строка под текстом.
- Удалить: значки скорости, числа знаков и времени чтения, кнопки «Редактировать», «ИИ», «Экспорт», поиск внутри заметки.
- Поиск остаётся над списком заметок.

## 11. Набор замеров

Первый шаг работ, до изменений промптов и валидатора.

- 50–100 реальных диктовок: WAV, сырой текст GigaAM и эталон для уровня B. Для 15–20 из них — эталоны C для «Делового» тона и для режима промпта.
- Категории: паразиты, самоисправления, повторы мыслей, числа и даты, термины, вопросы и просьбы, длинные рассуждения.
- Хранить вне репозитория или с согласия говорящего: это личная речь.
- Скрипт прогоняет набор через выбранный провайдер и модель и считает:
  - долю ответов, принятых валидатором;
  - сохранность чисел и терминов;
  - сжатие относительно сырого текста;
  - время ответа, медиану и 95-й процентиль;
  - ручную оценку на выборке: смысл сохранён, повторы убраны, звучит как говорящий.
- Прогоны: облачная модель по умолчанию, QVikhr 1.5B, QVikhr 3 4B, корпоративный шлюз.
