# Tranq: ребрендинг Голоска

Дата: 18 ноября 2026
Статус: на согласовании
Версия релиза: `3.0.0`, моя рекомендация: смена имени и bundle ID делает это новым приложением

---

## 1. Цель и зачем

Голосок становится Tranq. Это полная замена: имя, шрифты, иконка, идентификаторы, репозиторий, упаковка.

Зачем: пользователь хочет другое имя и фирменный вид. Tranq читается как спокойный, и это должно чувствоваться в оформлении.

Продукт не меняется. Видение из `2026-11-17-dictation-focus-design.md` остаётся в силе: лёгкая диктовка для macOS, русская речь, очистка текста, три способа обработки.

## 2. Что решено

| Тема | Решение |
| --- | --- |
| Имя | Tranq, всегда латиницей, в тексте без кавычек |
| Фирменный шрифт | Knewave, лицензия OFL. Только название и строчная буква q в иконке и строке меню |
| Шрифт интерфейса | Inter, лицензия OFL, с кириллицей. Заменяет системный шрифт везде |
| Стиль интерфейса | Notion и Linear: монохром, тонкие линии, без акцентного цвета |
| Иконка | Строчная буква q из Knewave на скруглённом квадрате. Светлая тема: белый фон, чёрная q. Тёмная тема: чёрный фон, белая q |
| Строка меню | Строчная буква q как шаблонное изображение вместо волны, цвет подстраивает система |
| Глубина замены | Полная: bundle ID, таргеты, файлы, папки, репозиторий |
| Данные старой версии | Не переносим. Tranq стартует с чистого листа, как у нового пользователя |
| Встроенные справочники | Остаются как есть. Десять наборов `Golosok/Dictionaries/*.json` лежат в бандле, поэтому новый пользователь получает их сразу. В папке данных будет пусто |
| Репозиторий | Переименовать `Nuteres/Golosok` в `Nuteres/Tranq`, согласовано пользователем |

## 3. Цели, не цели, антицели

Цели:
- Во всём, что видит пользователь, нет слова «Голосок» и Golosok.
- Шрифт интерфейса единый, переключается в одном месте.
- Иконка в Dock и Finder сама следует теме системы.
- Приложение собирается, тесты проходят, DMG собирается под новым именем.

Не цели:
- Перенос данных, настроек, ключей и прав из Golosok.
- Новые функции и изменение логики диктовки.
- Переработка структуры экранов. Меняется типографика и бренд, а не раскладка.
- Переименование локальной папки проекта на диске. Это делает сам пользователь.

Антицели:
- Яркий граффити-шрифт в основном тексте интерфейса. Приложение должно оставаться тихим.
- Остатки старого имени в пользовательском тексте, меню, окнах, README и релизах.
- Круглые скобки, квадратные скобки и фигурные скобки в новых пользовательских строках по правилам `AGENTS.md`.

## 4. Подходы

Глубина замены. Рассматривали три:

| Подход | Суть | Итог |
| --- | --- | --- |
| A. Только лицо | Меняется видимое. Внутри Golosok | Отвергнут |
| B. Лицо плюс упаковка | Плюс `Tranq.app` и `Tranq.dmg`. Bundle ID прежний | Рекомендовался, но не выбран |
| C. Полная замена | Плюс bundle ID, таргеты, файлы, репозиторий | **Выбран пользователем**. Чисто, но macOS считает это новым приложением |

Иконка, адаптивная к теме. Рассматривали два пути:

| Подход | Суть | Итог |
| --- | --- | --- |
| Файл Icon Composer | Один `.icon` с вариантами Default и Dark. Система сама подбирает вариант. Для macOS старше 26 Xcode собирает статичную иконку из варианта по умолчанию | **Рекомендуется** |
| Смена иконки в Dock на лету | `NSApp.applicationIconImage` по теме. Не затрагивает Finder и DMG | Отвергнут, работает только пока приложение запущено |

Минимум системы сейчас 13.5. Поэтому на macOS старше 26 иконка будет статичной белой, это принимается.

## 5. Дизайн

### Название и иконка
- Название набирается Knewave Regular, шрифт лежит в бандле. Используется в окне «О программе», онбординге и заголовке боковой панели.
- Строчная буква q берётся из Knewave и переводится в векторный контур один раз при подготовке ресурсов. Тот же контур идёт в иконку, строку меню и README.
- Иконка собирается в Icon Composer. Default: белый фон, чёрная q. Dark: чёрный фон, белая q. Mono тоже задаётся.
- Прежние `icon_idle*.png` и `AppLogo` заменяются.

### Типографика
- Все тексты интерфейса идут через `Font.ui` в `MonoStyle.swift`. Меняем реализацию на Inter, вызовы не трогаем.
- Шкала `UITextSize` сохраняется. Минимум 10 pt.
- Моноширинные и прочие явные `design:` проверяются поштучно, их шесть.
- Шрифты лежат в папке `Tranq/Fonts` и регистрируются через `ATSApplicationFontsPath`. Рядом лежат тексты лицензий OFL.

### Цвет
Палитра не меняется: нейтральный монохром и семантические цвета состояний. Акцентного цвета нет, главные кнопки чёрные в светлой теме и белые в тёмной.

## 6. Что заменяется при переименовании

| Область | Было | Станет |
| --- | --- | --- |
| Видимое имя | Голосок | Tranq. «Развернуть Голосок» превращается в «Развернуть Tranq» |
| Bundle ID | `kozak-developer.Golosok` | `kozak-developer.Tranq` |
| Таргеты и схема | `Golosok`, `GolosokTests`, `GolosokUITests` | `Tranq`, `TranqTests`, `TranqUITests` |
| Папки и файлы | `Golosok/`, `GolosokApp.swift`, `GolosokSynthProtocol.swift` | `Tranq/`, `TranqApp.swift`, `TranqSynthProtocol.swift` |
| Данные | `~/Library/Application Support/Golosok` | `.../Tranq` |
| Временные файлы | `tmp/Golosok` | `tmp/Tranq` |
| Метки очередей и логов | `Golosok.AppLogger.io`, `com.golosok.transcript.journal` | `Tranq.*`, `com.tranq.*` |
| Заголовок запросов | `X-Title: Golosok` | `X-Title: Tranq` |
| Переменные скриптов | `GOLOSOK_*` | `TRANQ_*` |
| Скрипты, CI | `Golosok.xcodeproj`, `Golosok.dmg`, схема `Golosok` | Tranq |
| Entitlements | `Config/Golosok.entitlements` | `Config/Tranq.entitlements` |
| Обновления | `Nuteres/Golosok` | `Nuteres/Tranq` |
| Документы | README, README_RU, AGENTS.md, docs/eval | Новое имя. Старые спеки в `docs/superpowers/specs` остаются как исторические |

Последствия для пользователей, принятые как есть: macOS запросит права на микрофон и универсальный доступ заново, автозапуск и настройки начнутся с нуля, Tranq встанет рядом со старым Голоском и не заменит его.

## 7. Ограничения

- Только GitHub. Работа идёт в ветке `feat/rebrand-tranq`, без PR, пока пользователь явно не попросит.
- Перед PR локально проходят тесты, сборка и линтеры.
- Переименование репозитория на GitHub делается последним шагом, после готовой ветки. Локальный remote потом обновляется.
- Бинарные ресурсы `gigaam.gguf`, `whisper-cli`, `llama-cli` не переименовываются.
- Каждый релиз прикладывает свежий `build/Tranq.dmg`.

## 8. На усмотрение исполнителя

- Как переводить q в контур: любым способом, дающим точный контур Knewave.
- Порядок правок и разбиение на коммиты.
- Как поступить с `icon_idle`-ресурсами и пустым `AccentColor`.
- Метка `MARKETING_VERSION` и тег `v3.0.0` согласно разделу о версиях.

## 9. Мои решения для проверки

1. Монохром без акцента: пользователь выбрал белую иконку, я распространил это на кнопки. Если нужен цвет, это отдельная задача.
2. Версия `3.0.0`. В `AGENTS.md` написано `1.X`, а в проекте уже `2.3.0`. Расхождение стоит поправить в `AGENTS.md`.
3. Структуру экранов не трогаем: интерфейс уже в духе Notion и Linear.
4. Минимум 13.5 остаётся. Адаптивная иконка работает с macOS 26.
5. Старые спеки не переписываем.
