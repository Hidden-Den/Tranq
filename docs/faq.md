# Частые вопросы

### macOS пишет, что приложение повреждено или от неустановленного разработчика

Сборка подписана без платного сертификата Apple Developer и не нотаризована. Выполните в Терминале:

```bash
xattr -cr /Applications/Tranq.app
```

### Текст распознаётся, но не вставляется

Tranq вставляет текст через `⌘ V`, для этого нужен Универсальный доступ. Проверьте, что Tranq включён в **Системные настройки → Конфиденциальность и безопасность → Универсальный доступ**.

После замены приложения новой версией права подтягиваются через минуту-две. Если не помогло, удалите Tranq из списка кнопкой «−» и добавьте снова.

### Не работает клавиша Fn

Одиночные модификаторы вроде `Fn` тоже требуют Универсального доступа. Ещё проверьте, что в **Системные настройки → Клавиатура** у клавиши `Fn` не назначено другое действие, например эмодзи или диктовка macOS.

### Текст вставляется без очистки

- Не выбрана модель очистки: **Настройки → Обработка**.
- Внешний API или шлюз не отвечает. Проверьте соединение кнопкой в **Настройки → Провайдер**.
- Модель изменила смысл, и проверка вставила текст без её правок. Сырую расшифровку и итог можно сравнить в истории.

### Модель путает мои термины

Добавьте слово в **Словарь → Мои слова** с вариантами, как его слышит распознавание. Или поправьте текст заметки в истории, словарь запомнит исправление.

### Можно диктовать по-английски

Да. Выберите Whisper Large-v3 Turbo или Medium в **Настройки → Распознавание**. Но Tranq в первую очередь сделан для русской речи.

### Будет ли версия для Windows, Linux или Intel Mac

Пока нет. Сейчас все силы уходят в версию для Mac на Apple Silicon.

### Сколько это стоит

Tranq бесплатный и с открытым кодом. Платить придётся только внешнему API, если выберете его для очистки.

### Как сообщить об ошибке

[Заведите issue](https://github.com/Hidden-Den/Tranq/issues/new/choose) и приложите версию приложения, версию macOS и шаги, чтобы повторить ошибку. Лог лежит в `~/Library/Application Support/Tranq/Logs`. Перед отправкой проверьте, что в нём нет личного текста.
