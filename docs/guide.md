# Руководство Tranq

## Установка

1. Скачайте `Tranq.dmg` со [страницы релизов](https://github.com/Hidden-Den/Tranq/releases/latest).
2. Перетащите `Tranq.app` в «Программы».
3. Снимите карантин. Сборка подписана без платного сертификата Apple Developer и не нотаризована, поэтому macOS блокирует первый запуск:

   ```bash
   xattr -cr /Applications/Tranq.app
   ```

   Другой способ: правый клик по `Tranq.app` → «Открыть» → «Открыть».
4. При первом запуске выдайте разрешения:
   - **Микрофон** — для записи речи.
   - **Универсальный доступ** — чтобы вставлять текст через `⌘ V` в активное окно и слышать клавишу `Fn`.

Модель распознавания GigaAM v3 уже лежит внутри приложения, докачивать ничего не нужно.

## Диктовка

По умолчанию диктовка включается клавишей `⌥ Пробел`. Её можно сменить на любое сочетание или на одиночный модификатор, например `Fn`.

Два режима клавиши:

- **Переключение.** Первое нажатие начинает запись, второе останавливает её и вставляет текст.
- **Рация.** Держите клавишу, пока говорите, отпустите — текст вставится.

`Esc` отменяет диктовку без вставки. Отменённая запись длиннее трёх секунд сохраняется в историю, чтобы сказанное не пропало.

Во время записи окно, куда пойдёт текст, подсвечивается рамкой. Подсветка выключается в **Настройки → Диктовка**.

Режим клавиши и звуки можно быстро переключить из значка в строке меню.

## Обработка текста

Tranq обрабатывает речь в два шага:

1. **Без модели.** Убираются звуки вроде «э-э» и заикания, расставляются заглавные буквы и абзацы. Этот шаг работает всегда.
2. **С моделью.** Языковая модель убирает слова-паразиты, самоисправления и повторы мыслей. Она не пересказывает и не сокращает речь, а слова и факты говорящего сохраняет.

Ответ модели проверяется. Если в нём пропало число, латинский термин или появилось слово, которого вы не говорили, вставляется текст первого шага.

Модель выбирается в **Настройки → Обработка**. Есть три варианта.

### Локальная модель

Работает без сети прямо на Mac. Приложение подскажет модель по объёму памяти:

| Модель | Размер | Памяти Mac |
| :--- | :--- | :--- |
| Gemma 4 E2B | 3,1 ГБ | от 8 ГБ, рекомендуется для 8 ГБ |
| Gemma 4 E4B | 4,2 ГБ | от 16 ГБ, рекомендуется для 16 ГБ и больше |
| T-lite 2.1 | 5,0 ГБ | от 16 ГБ |

Модель скачивается с Hugging Face по кнопке в настройках. Сравнение моделей: [замер ноября 2026](eval-local-models-2026-11.md).

### Внешний API

Готовые пресеты: OpenRouter, OpenAI, Anthropic, DeepSeek, Ollama. Укажите ключ и модель в **Настройки → Провайдер**, кнопка проверки сразу покажет, работает ли соединение. В разделе можно включить счётчики токенов и задержек.

### Корпоративный шлюз

Любой сервер с API в формате OpenAI, например внутренний шлюз компании. Если шлюз недоступен, скажем выключен VPN, вставляется текст первого шага, а на экране записи появляется пометка «Шлюз недоступен». Запасного перехода на внешний сервис нет: текст не уйдёт туда, куда вы его не отправляли.

## Длинные диктовки

Речь длиннее 1200 знаков делится на куски до 800 знаков по концам предложений. Каждый кусок чистится отдельно и вставляется абзацем. Кусок, который не прошёл проверку, вставляется как сказан, остальные чистыми.

## Правила

Раздел **Правила** в боковом меню задаёт тон для приложения или сайта в активной вкладке браузера. Например, деловой тон для рабочей почты или свободный для мессенджера.

Без правила везде одинаковая чистая речь. Тон меняет только стиль: он не отвечает вместо вас, не добавляет вежливых формул и не превращает поручение другому человеку в письмо этому человеку.

## Словарь

Раздел **Словарь** помогает распознаванию и очистке писать термины правильно.

- **Встроенные наборы:** IT, AI, бизнес, менеджмент, маркетинг, дизайн, финансы, HR, юриспруденция, медицина, психология, названия приложений. Наборы включаются и выключаются по одному.
- **Мои слова.** Добавьте слово и варианты, как его слышит распознавание. Например, «кубернетис» → Kubernetes.
- **Обучение.** Когда вы правите текст заметки в истории, словарь запоминает исправление.

Латинские термины пишутся латиницей, русские аббревиатуры вроде БТИ остаются кириллицей.

## История

Каждая диктовка сохраняется заметкой: итоговый текст, сырая расшифровка «Сказано» и запись голоса. Текст правится по клику.

Если главное окно скрыто, законченная диктовка открывает историю. Если окно открыто, новая заметка ждёт с точкой непрочитанного. Это можно выключить в **Настройки → Приложение**.

### Замок истории

Включается в **Настройки → Данные**. История открывается по Touch ID или паролю Mac, а заметки, звук и журнал диктовок шифруются на диске. Подробнее в разделе [Приватность](privacy.md#замок-истории).

## Настройки

| Раздел | Что внутри |
| :--- | :--- |
| Диктовка | горячая клавиша, режим клавиши, авто-вставка, звуки, подсветка окна |
| Распознавание | модель распознавания |
| Обработка | способ и модель очистки, инструкция модели, переход в словарь и правила |
| Провайдер | пресеты, адрес, ключ, проверка соединения, счётчики |
| Приложение | язык, тема, запуск при входе, скрытие из Dock, открытие истории, о программе |
| Данные | доступ для нейронок, логи, замок истории, стирание истории |

## Обновления

Tranq раз в несколько часов проверяет страницу релизов на GitHub и сообщает о новой версии. Чтобы обновиться, скачайте новый `Tranq.dmg`, замените приложение в «Программах» и снова выполните `xattr -cr /Applications/Tranq.app`.
