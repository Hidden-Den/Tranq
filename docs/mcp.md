# Доступ для нейронок

Tranq может отдать свой словарь ИИ-агенту: Claude Code, Cursor, Codex, Gemini CLI, Antigravity и любому другому клиенту MCP. Агент добавляет ваши термины с вариантами произношения, собирает тематические наборы, а с отдельным разрешением читает историю и находит слова, которые распознавание пишет неправильно.

## Как это устроено

В приложение встроен помощник `tranq-mcp`. Клиент запускает его и общается с ним по MCP через stdin и stdout, а помощник обращается к приложению через Unix-сокет в папке данных. По сети ничего не слушается, данные видит только агент, которого вы подключили.

Протокол сокета описан в [mcp/PROTOCOL.md](../mcp/PROTOCOL.md).

## Включение

**Настройки → Данные**, все переключатели по умолчанию выключены:

| Переключатель | Что разрешает |
| :--- | :--- |
| Доступ | читать словарь, добавлять слова, создавать свои наборы |
| Полный доступ | удалять любые слова, в том числе добавленные вами, и выключать наборы |
| История | читать ваши диктовки: текст уйдёт в модель агента |

Полный доступ и история включаются с предупреждением.

## Подключение клиента

Блок в настройках показывает готовый конфиг с путём до помощника.

- **Claude Code, Cursor, Gemini CLI, Antigravity** и другие клиенты с конфигом `mcpServers`: скопируйте вкладку JSON в конфиг клиента.
- **Codex** хранит серверы в TOML: скопируйте команду `codex mcp add` и выполните её в Терминале.

Больше настраивать ничего не нужно.

## Что умеет агент

| Инструмент | Действие |
| :--- | :--- |
| `list_dictionary_packs` | список наборов словаря |
| `list_user_words` | ваши слова |
| `list_pack_words` | слова набора |
| `set_pack_enabled` | включить или выключить набор |
| `add_words` | добавить слова |
| `remove_words` | удалить слова |
| `create_pack`, `delete_pack` | создать или удалить свой набор |
| `revert_agent_words` | откатить всё, что записал агент |
| `list_dictations` | прочитать прошлые диктовки |

## Ограничения

- Слова приходят пачками до 50 штук.
- У агента не больше 20 своих наборов, в каждом до 500 слов.
- Агент пишет только в ваш личный список или в свои наборы, встроенные словари он не меняет.
- Всё, что записал агент, помечено в экране словаря и снимается одним действием.
