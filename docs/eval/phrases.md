# Фразы для замера очистки

Как диктовать:

- Режим «Умная речь», обычная горячая клавиша без Shift.
- Диктовать в приложение без правил, например в Заметки.
- Одна фраза — одна диктовка, по порядку.
- Читать естественно, вместе с «ну», «короче» и повторами: их и проверяем.
- Сбился — продиктуй фразу заново. Выгрузка сама найдёт удачную попытку.
- Можно с перерывами и другими диктовками между блоками.

Эталоны лежат в `expected.jsonl`, при чтении на них лучше не смотреть.
