# Приватность и данные

Tranq сделан так, чтобы ваша речь оставалась у вас. Ниже описано, что уходит в сеть, что лежит на диске и как всё стереть.

## Что уходит в сеть

| Куда | Что | Когда |
| :--- | :--- | :--- |
| Выбранная вами модель очистки | текст расшифровки, без звука | только если выбран внешний API или шлюз |
| GitHub | запрос номера последней версии | раз в несколько часов |
| Hugging Face | скачивание модели | только когда вы сами нажали «Скачать» |

Звук не уходит никуда: распознавание идёт на вашем Mac. С локальной моделью очистки текст тоже не покидает Mac.

Аналитики, телеметрии и отчётов о сбоях нет. Счётчики токенов и задержек API хранятся только локально и по умолчанию скрыты.

## Что лежит на диске

Все данные лежат в `~/Library/Application Support/Tranq`:

- `Notes` — заметки истории.
- `Audio` — записи голоса к заметкам.
- `Logs` — лог приложения.
- `dictionary.json` — ваш словарь.
- `models` — скачанные модели.
- `telemetry.json` — локальные счётчики API.

Настройки, включая ключ API, хранятся в `~/Library/Preferences/nuter.Tranq.plist`. Ключ лежит там открытым текстом и доступен программам, запущенным под вашей учётной записью. Для работы с чувствительными данными используйте локальную модель или корпоративный шлюз.

Распознавание на короткое время пишет звук во временные файлы, доступные только вашей учётной записи, и удаляет их по окончании. После сбоя уборка при запуске удаляет остатки старше суток.

## Замок истории

Включается в **Настройки → Данные**.

- История открывается по Touch ID или паролю Mac.
- Заметки, звук и журнал диктовок шифруются на диске.
- Ключ живёт на этом Mac. На Mac с Secure Enclave он не покидает чип. На Mac без него ключ лежит в связке ключей входа, и защита зависит от вашего пароля.
- На другом Mac зашифрованная история не прочитается. Перед переездом выгрузите открытую копию кнопкой «Выгрузить».
- Лог не шифруется, но при включённом замке в него пишутся только длины и идентификаторы вместо текста, слова словаря тоже скрыты.

Замок не защищает от того, кто знает пароль вашей учётной записи macOS.

## Доступ для нейронок

По умолчанию выключен. Если включить, данные получает только MCP-клиент на вашем Mac, по сети приложение ничего не слушает. Доступ к истории включается отдельно и с предупреждением: текст диктовок уйдёт в модель, на которой работает агент. Подробнее: [Доступ для нейронок](mcp.md).

## Как всё стереть

- **Настройки → Данные → Стереть историю** удаляет заметки, звук, журнал, лог и ключ шифрования.
- Чтобы удалить всё, перенесите `Tranq.app` в корзину и удалите папку `~/Library/Application Support/Tranq` и файл `~/Library/Preferences/nuter.Tranq.plist`.
