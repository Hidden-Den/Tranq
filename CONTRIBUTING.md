# Как помочь проекту

Спасибо, что хотите помочь Tranq. Ошибки, идеи и исправления принимаются на русском и на английском.

Как устроено приложение, описано в [Tranq изнутри](docs/development.md).

## Куда писать

- **Ошибка** — [issue по шаблону](https://github.com/Hidden-Den/Tranq/issues/new/choose).
- **Идея или вопрос** — [обсуждения](https://github.com/Hidden-Den/Tranq/discussions).
- **Уязвимость** — не в открытый issue, а по правилам из [SECURITY.md](SECURITY.md).

## Что Tranq делает, а что нет

Tranq — лёгкая диктовка: нажал клавишу, сказал, вставился чистый текст. Главная ценность — очистка речи с сохранением слов и фактов говорящего. Основной язык — русский с латинскими терминами.

Предложения, которые не служат диктовке или усложняют интерфейс, скорее всего будут отклонены, даже если они полезны сами по себе. Если сомневаетесь, сначала обсудите идею в обсуждениях.

## Сборка из исходников

Нужны Mac на Apple Silicon, Xcode 26 или новее и Go 1.27 или новее.

```bash
git clone https://github.com/Hidden-Den/Tranq.git
cd Tranq
brew install go
scripts/fetch-deps.sh
open Tranq.xcodeproj
```

- `scripts/fetch-deps.sh` скачивает модель GigaAM и llama-server. Версии и контрольные суммы SHA-256 зафиксированы в скрипте.
- Каждая сборка в Xcode собирает помощник `tranq-mcp` из папки `mcp` и без Go падает. Зависимости Go лежат в `mcp/vendor`, сеть не нужна.
- Движок transcribe.cpp Xcode скачает сам как Swift-пакет.
- `⌘ R` собирает и запускает приложение.

Релизный DMG с ad-hoc подписью и hardened runtime:

```bash
scripts/build-dmg.sh
```

## Тесты

```bash
xcodebuild test -project Tranq.xcodeproj -scheme Tranq \
  -destination 'platform=macOS' -only-testing:TranqTests
```

```bash
cd mcp && go vet ./... && go test -mod=vendor -race ./...
```

Тестам не нужны модели: те, что требуют GigaAM, без модели пропускаются. CI прогоняет то же самое на каждый пулл-реквест.

Качество очистки меряется отдельным набором фраз, см. [docs/eval.md](docs/eval.md).

## Пулл-реквесты

1. Одно изменение — один пулл-реквест.
2. Перед отправкой прогоните тесты и `bash scripts/check-brand.sh`.
3. Новая логика покрывается тестами.
4. Сообщения коммитов в формате `тип: что сделано`, например `fix: вставка в Telegram`. Типы: `feat`, `fix`, `docs`, `chore`, `refactor`, `test`.

## Правила интерфейса

- Подписи — одно-два слова, подзаголовки короче восьми слов.
- Без скобок в тексте интерфейса и без обучающих абзацев.
- Никаких дублирующих кнопок на одном экране.
- Монохром: акцентного цвета нет. Единственный цвет `#CBFF6E` — рамка записи поверх чужого окна.
- Текст набирается Inter через `Font.ui`, Knewave только для названия.
- Имя приложения только `Tranq`, латиницей.
- Строки интерфейса живут в `Tranq/Localizable.xcstrings`. Правьте их в Xcode или сохраняйте его форматирование.

## Версии

`X.Y` — новые возможности, `X.Y.Z` — исправления. Версия задаётся в `MARKETING_VERSION`, тег релиза `vX.Y.Z`, к релизу прикладывается `Tranq.dmg`.
