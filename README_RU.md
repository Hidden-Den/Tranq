Голосовая диктовка для macOS. Нажал клавишу, сказал — в активное поле вставился чистый, лаконичный текст без слов-паразитов, оговорок и повторов. Речь распознаётся локально моделью Sber GigaAM v3; очистку текста делает языковая модель на выбор: локальная без сети, внешний API или корпоративный шлюз. Данные уходят только выбранной вами модели; единственная статистика — локальные счётчики токенов и задержек API, по умолчанию скрытые.

## Возможности

* **Распознавание без сети.** GigaAM v3 работает на устройстве, звук никуда не отправляется. Для английской речи доступны Whisper Large-v3 Turbo и Medium.
* **Очистка речи.** Когда настроена модель очистки, локальная или через API, убираются слова-паразиты, самоисправления и повторы мыслей, а слова и факты говорящего сохраняются. Без модели убираются только звуки и заикания. Числа и латинские термины защищены проверкой: если модель что-то потеряла или придумала, вставляется текст без её правок.
* **Правила приложений и сайтов.** Можно задать тон для приложения или сайта активной вкладки браузера, например деловой для рабочей почты. Без правила везде одинаковая чистая речь. У правил свой пункт в боковом меню.
* **Три способа обработки:**
  * локальные модели без сети, приложение рекомендует модель по памяти Mac;
  * внешний API: OpenRouter, OpenAI, Anthropic, DeepSeek, Ollama;
  * корпоративный шлюз в формате OpenAI. Если шлюз недоступен, например выключен VPN, вставляется текст без обработки и появляется пометка «Шлюз недоступен».
* **Термины.** Встроенные словари IT, бизнеса, HR, финансов и других областей. Латинские термины пишутся латиницей, русские аббревиатуры — кириллицей. Словарь учится на правках заметок.
* **Доступ для нейронок.** По умолчанию выключен. Когда включён в настройках, нейронка, подключённая по MCP, читает словарь и добавляет ваши слова с вариантами произношения, собирает свои тематические наборы, а с отдельно выданным доступом к истории читает прошлые диктовки и находит слова, которые распознавание калечит. Всё, что записала нейронка, помечено в экране словаря и снимается одним действием.
* **Вставка под курсор** в любое приложение. Два режима клавиши: переключение и рация.
* **История.** Заметки с текстом, сырой расшифровкой «Сказано» и записью голоса. Текст правится по клику.

## Установка

1. Скачайте `Tranq.dmg` из раздела [Releases](https://github.com/Nuteres/Tranq/releases).
2. Перетащите `Tranq.app` в системную папку `/Applications`.

### Снятие атрибута карантина (Gatekeeper)

Приложение поставляется как Open Source без платной подписи Apple Developer. Если macOS блокирует первый запуск, выполните в Терминале:

```bash
xattr -cr /Applications/Tranq.app
```

*(Или через GUI: зажать Control + правый клик по `Tranq.app` -> Открыть -> Подтвердить).*

## Боковое меню и настройки

В боковом меню четыре пункта: Словарь, Правила, История, Настройки. Законченная диктовка открывает историю, только пока главное окно скрыто; при открытом окне новая заметка ждёт с точкой непрочитанного.

В настройках шесть разделов, они показаны в боковом меню:

* **Диктовка:** горячая клавиша, режим клавиши, авто-вставка, звуки.
* **Распознавание:** модель распознавания.
* **Обработка:** движок, модель обработки, инструкция модели, переходы в словарь и правила.
* **Провайдер:** пресеты, адрес, ключ, проверка соединения, телеметрия.
* **Приложение:** язык, цвет интерфейса, запуск при входе, скрытие в Dock, открытие в истории, о программе.
* **Данные:** доступ для нейронок, логи, замок истории, стирание истории.

## Системные разрешения

* **Микрофон:** для захвата звукового потока с микрофона.
* **Универсальный доступ (Accessibility):** для эмуляции клавиатурной вставки (`⌘ + V`) в активное окно и отслеживания модификаторов (`Fn`).

## Управление

* **Глобальная клавиша (по умолчанию `⌥ + Пробел` или `Fn`):**
  * В режиме **Переключение**: 1-е нажатие включает запись, 2-е — останавливает и вставляет текст.
  * В режиме **Рация**: удержание клавиши ведёт запись, отпускание — распознаёт речь.
* **`ESC`:** мгновенная отмена диктовки без сохранения и вставки.
* **Значок в строке меню:** выбрать Переключение или Рацию, включить и выключить звуки, открыть приложение и настройки. `⌘ + ,` открывает настройки.

## Доступ для нейронок

Tranq отдаёт свой словарь нейронке. В приложении лежит помощник `tranq-mcp`: он говорит по MCP через stdin и stdout, а до приложения достаёт через Unix-сокет в папке данных. По сети не слушает никто, данные видит только тот агент, которым вы и так пользуетесь.

**Переключатели в настройках, раздел «Данные», все выключены, пока вы их не включите:**

* **Доступ** — читать словарь, добавлять слова, создавать свои наборы.
* **Полный доступ** — удалять любое слово, в том числе вбитое вами руками, и выключать наборы. Включается с предупреждением.
* **История** — читать ваши диктовки. Включается с предупреждением: текст уйдёт в модель, на которой работает агент.

**Подключение клиента.** Блок в настройках показывает конфиг с путём до помощника. Клиентам, которые читают конфиг `mcpServers` — Claude Code, Cursor, Gemini CLI, Antigravity — подходит вкладка JSON. Codex хранит серверы в TOML, поэтому для него блок показывает команду `codex mcp add` для терминала. Скопируйте показанное, больше настраивать нечего.

**Что получает нейронка:** `list_dictionary_packs`, `list_user_words`, `list_pack_words`, `set_pack_enabled`, `add_words`, `remove_words`, `create_pack`, `delete_pack`, `revert_agent_words`, `list_dictations`. Слова приходят пачками до 50 штук; своих наборов у агента не больше 20, в каждом до 500 слов. Его слова ложатся в ваш личный список или в его набор, но никогда внутрь встроенного словаря, а в экране словаря есть одно действие, которое забирает их все назад.

Протокол сокета описан в [mcp/PROTOCOL.md](mcp/PROTOCOL.md).

## Замок истории

Включается в настройках, раздел «Данные». Историю открывает Touch ID, заметки, звук и журнал диктовок лежат на диске зашифрованными. Ключ живёт только на этом Mac: на другом Mac история не прочитается, поэтому перед переездом выгрузите открытую копию кнопкой «Выгрузить». Лог приложения не шифруется, но текст диктовок в него при замке не пишется. Распознавание на короткое время пишет звук во временные файлы, доступные только вашей учётной записи, и сразу их удаляет. «Стереть историю» убирает и записи, и ключ; при включённом замке новая история шифруется новым ключом.

## Сборка из исходников

```bash
# 1. Клонировать репозиторий
git clone https://github.com/Nuteres/Tranq.git
cd Tranq

# 2. Установить Go 1.27 или новее, он нужен для сборки встроенного помощника tranq-mcp
brew install go

# 3. Скачать модель GigaAM и llama-server; версии и контрольные суммы SHA-256 зафиксированы в скрипте
scripts/fetch-deps.sh

# 4. Открыть проект в Xcode
open Tranq.xcodeproj
```

Каждая сборка приложения в Xcode запускает фазу сборки Go для `tranq-mcp` и без Go падает. Она берёт зависимости из vendor, поэтому сеть Go не нужна.

Для сборки и запуска нажмите `⌘ + R` в Xcode. Движок transcribe.cpp Xcode скачает сам как Swift-пакет.

Релизный DMG с ad-hoc подписью и hardened runtime:

```bash
scripts/build-dmg.sh
```

Unit-тесты также запускаются в GitHub Actions при каждом пуше в `main` и в пулл-реквестах. Модели и бинарники им не нужны.
