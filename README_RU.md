Нативная система голосового ввода и офлайн-расшифровки медиафайлов на базе Sber GigaAM v3 и Whisper (Large-v3 Turbo / Medium) с аппаратным ускорением на Apple Silicon. Распознавание речи работает на 100% локально; опциональная постобработка через ИИ подключается напрямую к вашему провайдеру или локальной Ollama. Полное отсутствие телеметрии и сторонних трекеров.

## Архитектура и функциональные возможности

* **Локальное распознавание речи (100% офлайн):** Инференс распознавания речи выполняется целиком на устройстве без интернета. Аудиопоток не передаётся по сети. В коде полностью вырезана любая телеметрия, аналитика и сбор метрик.
* **Direct Input (Прямой ввод):** Нажатие глобальной горячей клавиши (по умолчанию `⌥ + Пробел` или системная клавиша `Fn`) запускает запись — распознанный текст автоматически подставляется под активный курсор в любом приложении (VS Code, Notion, Telegram, Xcode, Obsidian, Slack, браузеры).
* **Аппаратное ускорение:** Модели оптимизированы под чипы Apple Silicon (M1–M5) с использованием Core ML, Apple Neural Engine (ANE) и Metal Performance Shaders без перегрева процессора.
* **Два режима диктовки:**
  * **Переключение:** первое нажатие начинает запись, второе — завершает, распознаёт и вставляет текст.
  * **Рация (Push-to-Talk):** запись длится, пока клавиша зажата; при отпускании текст моментально транскрибируется и вставляется.
* **Пакетная офлайн-расшифровка:** Транскрибация аудио- и видеофайлов любой продолжительности без подключения к интернету (MP3, WAV, M4A, AAC, FLAC, OGG, OPUS, MP4, MOV, WebM, MKV).
* **Автономный Air-Gapped SLM синтез (100% офлайн):** Интеллектуальная обработка и очистка текста на локальных малых языковых моделях (QVikhr 2.5 1.5B, Qwen 2.5 1.5B / 0.5B, Llama 3.2 1B) через Metal GPU ускорение на Apple Silicon без отправки данных во внешние сети.
* **Адаптивное обучение и учет манеры речи:** Алгоритм запоминает специфические слова, термины и англицизмы говорящего, а также автоматически учится на ручных правках пользователя.
* **Встроенный справочник IT, Менеджмента и Бизнеса:** База из сотен готовых терминов и фонетических автозамен («кубер» → `Kubernetes`, «но восемь» → `n8n`) с инлайн-редактированием и категоризацией.
* **Прямая постобработка через внешний ИИ (опционально):** Редактирование, пунктуация и суммаризация через прямое подключение со своими ключами (OpenAI, Groq, DeepSeek) или локальную Ollama. Без сторонних серверов-прокси.

## Установка

1. Скачайте `Golosok.dmg` из раздела [Releases](https://github.com/Nuteres/Golosok/releases).
2. Перетащите `Golosok.app` в системную папку `/Applications`.

### Снятие атрибута карантина (Gatekeeper)

Приложение поставляется как Open Source без платной подписи Apple Developer. Если macOS блокирует первый запуск, выполните в Терминале:

```bash
xattr -cr /Applications/Golosok.app
```

*(Или через GUI: зажать Control + правый клик по `Golosok.app` -> Открыть -> Подтвердить).*

## Системные разрешения

* **Микрофон:** для захвата звукового потока с микрофона.
* **Универсальный доступ (Accessibility):** для эмуляции клавиатурной вставки (`⌘ + V`) в активное окно и отслеживания модификаторов (`Fn`).

## Управление

* **Глобальная клавиша (по умолчанию `⌥ + Пробел` или `Fn`):**
  * В режиме **Переключение**: 1-е нажатие включает запись, 2-е — останавливает и вставляет текст.
  * В режиме **Рация**: удержание клавиши ведёт запись, отпускание — распознаёт речь.
* **`ESC`:** мгновенная отмена диктовки без сохранения и вставки.
* **Меню в строке состояния (Menu Bar):** быстрый доступ к истории последних диктовок, копированию и настройкам.

## Сборка из исходников

```bash
# 1. Клонировать репозиторий
git clone https://github.com/Nuteres/Golosok.git
cd Golosok

# 2. Скачать веса модели GigaAM
curl -L -o Golosok/gigaam.gguf https://huggingface.co/memoravox/gigaam-v3-e2e-rnnt-gguf/resolve/main/gigaam-v3-e2e-rnnt-Q8_0.gguf

# 3. Открыть проект в Xcode
open Golosok.xcodeproj
```

Для сборки и запуска нажмите `⌘ + R` в Xcode, либо соберите через терминал:

```bash
xcodebuild -project Golosok.xcodeproj -target Golosok -configuration Release build
```
