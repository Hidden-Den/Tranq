Голосовая диктовка для macOS. Нажал клавишу, сказал — в активное поле вставился чистый, лаконичный текст без слов-паразитов, оговорок и повторов. Речь распознаётся локально моделью Sber GigaAM v3; очистку текста делает языковая модель на выбор: локальная без сети, внешний API или корпоративный шлюз. Телеметрии нет.

---

## Возможности

* **Распознавание без сети.** GigaAM v3 работает на устройстве, звук никуда не отправляется. Для английской речи доступны Whisper Large-v3 Turbo и Medium.
* **Очистка речи.** Когда настроена модель очистки, локальная или через API, убираются слова-паразиты, самоисправления и повторы мыслей, а слова и факты говорящего сохраняются. Без модели убираются только звуки и заикания. Числа и латинские термины защищены проверкой: если модель что-то потеряла или придумала, вставляется текст без её правок.
* **Правила приложений и сайтов.** Можно задать тон для приложения или сайта активной вкладки браузера, например деловой для рабочей почты. Без правила везде одинаковая чистая речь, если не включён прямой ввод.
* **Режим промпта.** Основная клавиша с Shift превращает одну диктовку в запрос к нейросети. Включается в настройках.
* **Три способа обработки:**
  * локальные модели без сети, приложение рекомендует модель по памяти Mac;
  * внешний API: OpenRouter, OpenAI, Anthropic, DeepSeek, Ollama;
  * корпоративный шлюз в формате OpenAI. Если шлюз недоступен, например выключен VPN, вставляется текст без обработки и появляется пометка «Шлюз недоступен».
* **Термины.** Встроенные словари IT, бизнеса, HR, финансов и других областей. Латинские термины пишутся латиницей, русские аббревиатуры — кириллицей. Словарь учится на правках заметок.
* **Вставка под курсор** в любое приложение. Два режима клавиши: переключение и рация.
* **История.** Заметки с текстом, сырой расшифровкой «Сказано» и записью голоса. Текст правится по клику.

## Установка

1. Скачайте `Tranq.dmg` из раздела [Releases](https://github.com/Nuteres/Tranq/releases).
2. Перетащите `Tranq.app` в системную папку `/Applications`.

### Снятие атрибута карантина (Gatekeeper)

Приложение поставляется как Open Source без платной подписи Apple Developer. Если macOS блокирует первый запуск, выполните в Терминале:

```bash
xattr -cr /Applications/Tranq.app
```

*(Или через GUI: зажать Control + правый клик по `Tranq.app` -> Открыть -> Подтвердить).*

## Системные разрешения

* **Микрофон:** для захвата звукового потока с микрофона.
* **Универсальный доступ (Accessibility):** для эмуляции клавиатурной вставки (`⌘ + V`) в активное окно и отслеживания модификаторов (`Fn`).

## Управление

* **Глобальная клавиша (по умолчанию `⌥ + Пробел` или `Fn`):**
  * В режиме **Переключение**: 1-е нажатие включает запись, 2-е — останавливает и вставляет текст.
  * В режиме **Рация**: удержание клавиши ведёт запись, отпускание — распознаёт речь.
* **`ESC`:** мгновенная отмена диктовки без сохранения и вставки.
* **Клавиша с Shift:** одна диктовка в режиме промпта, если он включён.
* **Значок в строке меню:** открыть приложение и настройки.

## Сборка из исходников

```bash
# 1. Клонировать репозиторий
git clone https://github.com/Nuteres/Tranq.git
cd Tranq

# 2. Скачать модель GigaAM и llama-server; версии и контрольные суммы SHA-256 зафиксированы в скрипте
scripts/fetch-deps.sh

# 3. Открыть проект в Xcode
open Tranq.xcodeproj
```

Для сборки и запуска нажмите `⌘ + R` в Xcode. Движок transcribe.cpp Xcode скачает сам как Swift-пакет.

Релизный DMG с ad-hoc подписью и hardened runtime:

```bash
scripts/build-dmg.sh
```

Unit-тесты также запускаются в GitHub Actions при каждом пуше в `main` и в пулл-реквестах. Модели и бинарники им не нужны.
