# Протокол двери Tranq

Приложение слушает Unix-сокет `mcp.sock` в папке данных (`~/Library/Application Support/Tranq/mcp.sock`).
Построчный JSON, UTF-8: одна строка — один запрос, одна строка — один ответ. Имена полей в `snake_case`.
Swift и Go следуют этому файлу буквально.

```
запрос:  {"cmd": "<имя>", "args": {…}}
успех:   {"ok": true,  "data": <значение>, "language": "ru"}
отказ:   {"ok": false, "error": "<текст для человека>", "language": "ru"}
```

`language` — язык приложения, `ru` или `en`. Названия наборов и тексты `error` идут на нём.
Нечитаемая строка и неизвестная команда дают `ok: false` с понятным текстом, соединение остаётся открытым.
Любая команда сначала проходит проверку уровня доступа; отказ приходит как `ok: false` с текстом, который агент покажет человеку.

## Команды

| cmd | инструмент MCP | args | data |
|---|---|---|---|
| `packs` | `list_dictionary_packs` | нет | `[{"id","title","word_count","enabled","source":"builtin\|agent"}]` |
| `words` | `list_user_words` | нет | `[{"spelling","variants":{"ru":[…],"en":[…]},"source":"manual\|learned\|mcp","hits","last_used"}]`, `last_used` — ISO 8601 или `null` |
| `set_pack` | `set_pack_enabled` | `{"id","enabled"}` | объект набора как в `packs`, с `source` |
| `add_words` | `add_words` | `{"words":[{"spelling","variants":{"ru":[…],"en":[…]},"force_case"}],"pack_id"}`, `pack_id` необязателен | `{"added":["…"],"skipped":{"<написание>":"<причина>"}}` |
| `remove_words` | `remove_words` | `{"spellings":["…"],"pack_id"}`, `pack_id` необязателен | `{"removed":["…"],"skipped":{"<написание>":"<причина>"}}` |
| `revert_agent_words` | `revert_agent_words` | нет | `{"removed_words":N,"removed_variants":M,"removed_packs":K}` |
| `create_pack` | `create_pack` | `{"title"}` | `{"id","title","created"}` |
| `delete_pack` | `delete_pack` | `{"id"}` | `{"id","title","removed_words"}` |
| `pack_words` | `list_pack_words` | `{"id"}` | `[{"spelling","variants":{"ru":[…],"en":[…]}}]`, оба языка всегда |
| `dictations` | `list_dictations` | `{"limit":20}` | `[{"date","spoken","text"}]`, `date` — строка как в истории |

Правила:

- `set_pack` с `enabled: false` — это выключение набора, оно требует полного доступа. Дверь выводит это из `enabled`, отдельного флага в запросе нет.
- `add_words` больше 50 слов отклоняется целиком. Пустой список — тоже.
- Слово с негодным вариантом, равным написанию или короче двух символов, добавляется без этого варианта. Причина идёт в `skipped` под ключом `"<написание> / <вариант>"`, а само слово остаётся в `added`.
- Наборы агента. `create_pack` создаёт набор с идентификатором `agent-` и восемью шестнадцатеричными знаками. Название одно на оба языка, от 1 до 60 знаков, не совпадает без учёта регистра с названием встроенного набора. Повтор названия набора агента возвращает прежний набор с `created: false`, и на пределе тоже. Наборов агента не больше 20, слов в наборе не больше 500.
- `pack_id` в `add_words` и `remove_words`: ключ отсутствует или `null` значит «Мои слова». Любое другое значение, кроме непустой строки, включая `""`, это отказ без записи. Со `pack_id` команды работают только с набором агента и не трогают «Мои слова», без него не трогают наборы. Встроенный и неизвестный `pack_id` дают отказ. Пачка, которая не помещается в 500 слов набора, отклоняется целиком; слова, которые сливаются с существующими, место не занимают.
- `create_pack`, `delete_pack`, `pack_words` и команды со `pack_id` требуют только включённого доступа. `pack_words` и `delete_pack` на встроенный набор отказывают: состав встроенных наборов не раскрывается. `revert_agent_words` удаляет и наборы агента.
- `dictations`: `limit` по умолчанию 20, больше 100 обрезается до 100, ноль и отрицательное дают 20. Заметки без сырой расшифровки пропускаются.
- Сокет принимает несколько соединений одновременно, ответ уходит только своему клиенту.
- Одновременно открыто не больше 8 соединений. Девятое получает одну строку `{"ok":false,"error":"…","language":"…"}` сразу при подключении и закрывается. Строка запроса длиннее 1 МиБ получает такой же отказ и закрытие. Клиент читает первую строку как ответ на свой запрос и показывает `error` человеку.
- Пустая строка запроса игнорируется, ответа на неё нет.
